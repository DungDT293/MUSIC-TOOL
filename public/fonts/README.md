# Fonts

Place bundled `.woff2` font files in this directory so the built-in font list
loads reliably offline. The app expects these filenames:

- `Inter-Variable.woff2`
- `Roboto-Variable.woff2`
- `OpenSans-Variable.woff2`
- `Montserrat-Variable.woff2`
- `Lato-Variable.woff2`
- `Merriweather-Variable.woff2`
- `SourceSans3-Variable.woff2`
- `SourceSerif4-Variable.woff2`
- `BebasNeue-Regular.woff2`
- `Anton-Regular.woff2`
- `Oswald-Variable.woff2`
- `PlayfairDisplay-Variable.woff2`
- `DMSerifDisplay-Regular.woff2`
- `Poppins-Variable.woff2`
- `Manrope-Variable.woff2`
- `DMSans-Variable.woff2`
- `BeVietnamPro-Variable.woff2`
- `NotoSansVietnamese-Variable.woff2`
- `Pacifico-Regular.woff2`
- `DancingScript-Variable.woff2`

All of these fonts are open-source (OFL/Apache). Use the official sources to
download the exact weights and variants you want to ship.
