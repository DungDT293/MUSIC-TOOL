## Luồng hoạt động & tương tác (suy ra từ DOM)

1. Rail trái đổi panel: Composition → Analyzers → Effects → Automations → Media → Projects → Lyrics.
2. Composition là cây 3 tầng: nhóm (Visualizer / Particles Glow / Particles / Background Layer) → layer (2D Visualizer, 3D Particles, 2D Image, 2D Video).
3. Panel phải đổi theo layer đang chọn: tab Objects / Visualizer, rồi các accordion Preset, Spectrum layers, General, Positioning & Size, Basics.
4. Preset là lưới thumbnail 38×38, 6 cột; bấm là áp vào layer sóng đang chọn.
5. Timeline: zoom, timecode, transport, waveform, track theo layer; kéo playhead để seek.
6. Menu trên: File (Export/New/Save/Save As/Close), Edit, Project (Rename, Unpublish, Thumbnail, Custom resolution, Set background, Organize tracks), View, Help (system info, changelog, export JSON/log).
7. Chuột phải trên canvas/layer mở context menu: Choose preset, Add automation, Enable/Disable blur, Set background, Duplicate, Delete, Remove, Reset, Save preview as image, Save as this preset, Open external preview, Edit image.

## Giới hạn của lần bóc tách này

- Trang là SPA; dữ liệu lấy từ DOM đang render, không phải API nội bộ.
- Preset chỉ lấy được **id** (từ URL thumbnail trên Firebase Storage), không có tên hiển thị vì UI dùng tooltip ảnh.
- Menu và context menu dùng chung `role="menuitem"` nên phần đầu mỗi menu có thể lẫn mục context menu.
- Không bấm các hành động phá huỷ (Delete/Remove/Close/Save) để giữ nguyên project.
