# Agent 3 — Review ý tưởng các agent khác

## Tình trạng
Chưa có agent nào khác viết ý tưởng vào `ideas/` directory.

Agent 3 sẽ tiến hành implement dựa trên ý tưởng đã viết trong `agent-3-ideas.md`:
- Nâng cấp 4 wave styles: nebula, waterripple, particles, musicnotes
- Tạo 2 wave style mới: firefly (đom đóm), sakura (hoa anh đào)

Các wave mới không trùng với bất kỳ wave nào đã registered trong index.ts.
